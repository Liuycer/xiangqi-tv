# Phase 17 分析输入与状态联动报告

测试设备：Tmall MagicBox_M_30_F，WebView 74，1920×1080 应用画布

## 候选高亮

- 三路候选均可被预览和确认，不会直接执行走棋。
- 候选起点使用紫色虚线框，终点使用紫色实框，避免和既有遥控焦点、选棋、合法落点、上一步及将军状态混淆。
- 鼠标移入候选卡片或遥控器焦点移动至候选时，左侧棋盘立即显示临时高亮；鼠标移开后取消临时预览。
- 点击候选卡片或遥控器按 OK 后，分析面板立即关闭，棋盘继续保留高亮，右侧“局面分析”按钮显示所选中文着法。
- 重新开始、悔棋、实际走子、切换模式或开始新局面时，高亮和旧分析结果一起清除。

## 输入联动

| 操作 | 鼠标 | 遥控器 |
| --- | --- | --- |
| 打开分析 | 点击右侧按钮 | 操作区第七项按 OK |
| 切换强度 | 直接点击 | 方向键移动，OK 确认 |
| 预览候选 | 鼠标悬停候选卡片 | 方向键移动至候选 |
| 确认候选 | 点击候选卡片，自动返回棋盘 | 候选上按 OK，自动返回棋盘 |
| 取消分析 | 点击关闭或遮罩 | BACK |

分析界面改为兼容 WebView 74 的右侧窄面板，1920×1080 下棋盘和三路候选同时完整可见。真机验证中，鼠标点击和遥控器焦点预览/OK 确认均成功显示棋盘起终点；确认后自动返回棋局，对局手数保持为 0，证明候选确认没有落子。

## 请求与错误状态

- AI 自动走棋时分析入口禁用，避免两个请求争用单引擎锁。
- 悔棋、落子、重开、模式切换和应用进入后台时，正在运行的分析会被取消。
- 每个请求带有本地序列号，即使网络层忽略取消信号，旧响应也无法覆盖新局面。
- 网络错误只显示在分析面板，原有本地游戏和简单档本地 AI 不受影响。
