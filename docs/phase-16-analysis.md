# Phase 16 云端局面分析报告

测试设备：Tmall MagicBox_M_30_F，WebView 74，1920×1080 应用画布
云端引擎：2C2G VPS，Pikafish，Threads=2，Hash=128MB，MultiPV=3

## 用户界面

- 右侧操作区新增“局面分析”，不改变棋盘面积与原有左右比例。
- 分析使用右侧面板，完整保留左侧棋盘视野；上部显示红方视角评价、评价条与搜索强度，下部显示三路候选着法。
- 快速、标准、深入分别使用 1500ms、3000ms、5000ms 搜索时间。
- 每路候选显示第一着、评价、实际深度、节点数，以及最多八个半回合的中文主变化。
- 鼠标可直接点击强度、重新分析和关闭；遥控器可用方向键、OK 与 BACK 完成相同操作。
- Phase 17 补齐了候选预览与确认：鼠标悬停或遥控器焦点可即时预览，点击或按 OK 后返回棋局并保留起终点高亮，不会直接执行走棋。

## 请求生命周期

- 打开面板后自动分析当前局面。
- 切换强度会基于同一局面重新发起分析。
- 关闭面板、切换后台、悔棋、重开、走子或开始更新的请求时，旧请求会被取消并失效。
- 即使底层请求没有及时响应取消信号，请求序列校验也会阻止旧结果覆盖新局面。
- 分析和 AI 走棋继续共用同一个云端客户端，AI 思考期间不会开放分析入口。
