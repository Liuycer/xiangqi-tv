# Phase 41 胜局烟花与终局音效

## 目标与触发规则

电视端在玩家获胜后播放短暂、清晰且不会阻塞操作的庆祝效果，终局展示以电视前的人为中心：

- 人机对战中红方为玩家。红方获胜时播放烟花和庆祝音效；黑方 AI 获胜时只播放低调的结束音效；
- 本地双人模式中任一方获胜都播放烟花和庆祝音效；
- 和棋不播放烟花；
- 关闭“走子动画”或系统启用 `prefers-reduced-motion` 时不播放烟花；关闭音效时不播放终局音效。

终局策略位于 `web/src/experience/finish-celebration.ts`，不依赖 Vue 或 Canvas，并用单元测试覆盖人机红胜、AI 黑胜、本地红黑胜和和棋。

## 轻量实现

`VictoryCelebration.vue` 使用一个全屏、不可点击的 Canvas 2D 图层，不加载图片、视频或音频资源。正式参数为：

| 参数 | 数值 |
| --- | ---: |
| 播放时长 | 2.5 秒 |
| 内部画布上限 | 1280 × 720 |
| 帧率上限 | 24 fps |
| 绽放次数 | 4 |
| 粒子总上限 | 96 |

画布由 CSS 放大到 1080P 应用缓冲，再由盒子输出到 4K 电视。每一帧只清空画布、更新简单重力和绘制线段尾迹，不使用阴影、模糊、滤镜或大图纹理。

庆祝音效继续通过 Web Audio 振荡器实时合成。胜利音效扩展为五个上行音符；AI 获胜使用两个较低的下行音符，不增加 APK 音频资源。

## 生命周期与安全清理

以下操作会立即停止动画、取消下一帧并清空粒子：

- 动画自然播放完成；
- 重新开始或进入新一局；
- 打开棋手档案、设置或历史对局；
- 关闭走子动画；
- 应用进入后台或组件销毁。

Canvas 使用 `pointer-events: none`，不会拦截鼠标或遥控器操作。动画结束后不保留定时器、`requestAnimationFrame` 或粒子数组。

## 天猫魔盒实机验收

在 `192.168.3.11:5555` 的 MagicBox_M_30_F / WebView 74 上用临时自动触发版本完成视觉与资源采样，随后移除预览入口并重新构建正式版。

第一版 1920×1080、30fps、112 粒子在播放中 CPU 采样约为 117%～150%。最终版调整为 1280×720、24fps、96 粒子后约为 85%～121%，播放结束回到 0% 附近；高负载只持续约 2.5 秒。播放期间 Total PSS 约 120MB，正式版稳定后约 108MB，盒子物理内存约 980MB，余量充足。

Android `gfxinfo` 只记录 WebView 原生容器的少量帧，不能准确反映 Chromium Canvas 帧率，因此验收同时采用实机截图、进程 CPU、PSS、动画结束清理、前台 Activity 和崩溃日志。
