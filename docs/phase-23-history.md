# Phase 23 历史对局与回放

Phase 23 将历史数据、AI 复盘结果和回放状态留在服务器，电视盒子只负责按需读取与展示。

## 服务端

- `GET /v1/xiangqi/games` 按玩家分页返回最近对局、时间、结果、难度、手数和 AI 分析概况。
- `GET /v1/xiangqi/games/{gameId}` 返回完整着法及逐手分析数据。
- 查询继续使用 Bearer Token，且详情必须同时匹配 `playerId`，不同客户端身份不能读取对方记录。
- 列表查询只返回摘要；逐手数据在选择某盘后加载，避免低性能客户端一次接收全部棋谱。

## 电视端

- 操作区新增“历史对局”。左侧显示最近 20 盘，右侧显示只读棋盘、对局概况与回放控制。
- 鼠标可直接选择对局并点击“上一手 / 下一手”。
- 遥控器使用上下键切换对局、左右键逐手回放，BACK 关闭。
- 回放在浏览器内按 UCI 着法重建当前棋盘，不启动本地搜索，也不会修改当前正在进行的棋局。
- 历史数据读取失败只在弹层内提示，不会影响下棋和本地 AI。

## 冒烟验证

- Python 服务文件语法编译通过。
- Vue TypeScript 检查与生产构建通过。
